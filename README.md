# Zemen's Portfolio

## Run the app locally

1. Clone this repository to your local machine:

```bash
git clone https://github.com/zementeshome/zemen-teshome-portfolio.git
```

2. Navigate into the project directory:

```bash
cd sprint-1
```

3. Install dependencies

```bash
npm install
```

4. Run the app

```bash
npm run start
```

5. Default browser should automatically open the app at

```url
http://localhost:3000/
```
